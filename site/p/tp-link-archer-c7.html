I am running an Archer C7 v2 on OpenWRT. Works flawlessly. Some notes though: - 5ghz only worked after manually inserting the latest firmware blob for the qca9880 chip and setup only works via shell for it, setting any options for it from the web interface breaks stuff - it's fast enough... I'm running a freeradius2 server on it, SMB shares on two 32gb USB pendrives, miniDLNA, DHCP for ~50 physical and virtual clients, a VPN tunnel to a VPS and so on. Never hits full load. - 2.4ghz range is massive, 5ghz less so obviously... - it is absolutely stable however, uptime exceeds two months and the only reason for shutting it down back then was a move, almost nine months before that If you're simply looking for APs I would recommend Unifi UAP-AC-Pros though.
