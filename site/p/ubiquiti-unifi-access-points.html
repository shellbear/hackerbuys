I control three UniFi access points from ubiquiti software running on my Ubuntu server. They're powered over Ethernet from a switch and so unobtrusive - the only cord is the Ethernet cord. The management software is quite nice and I can access it from my phone or over http - no cloud necessary. My router is an edgerouter-4 with a fiber port which is also from ubiquiti but for some reason it's not controlled by the ubiquiti controller. It has a web interface that's powerful but a bit of a mess in the sense it's managing an advanced router and there's just so much you can do you can't possibly have a nice interface for everything. This has all been running 10+ years with very very little maintenance. It just keeps going.
