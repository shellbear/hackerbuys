You probably do that a lot now, but XP doesn't do that. XP has no search function in the Start menu. Hell, I don't recall Vista having that, either. Explorer (the file browser, not the browser browser) in XP is far more simplistic than you remember it. Again, limitations mostly come down to search and quality-of-life stuff that we now take for granted. Snipping tool. Being able to smack Print Screen and quickly crop and annotate a screenshot is awesome. XP doesn't do that OOTB. Greenshot really was the freeware gem you remember it being, to be fair. XP does get a lot of things right. Highly legible and consistent UI elements with clear visual feedback and color coding. Control Panel being a unified portal for all Windows settings.
