I followed this guide mostly on my PW4 and found the instructions to be a bit lacking / out-of-date. Dropping this as a warning for people trying this out - your Kindle firmware should be < 5.13.X. You need to be very careful about auto-updates that'll undo a jailbreak so put it on aiplane mode until you jailbreak it. After you do, I'd recommend you then install KUAL and then MobileRead Package Installer so that you can install the mod that prevents auto-updates and then you can install and control USBNetwork in a more user-friendly way.
