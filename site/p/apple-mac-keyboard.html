One thing I don't like about the default mac keyboard is the weird placement of the command key. If you are a touch typist and learned by rote to type with your pinky, the command key placement on the mac just sucked. I'm not saying Windows got this right, but MS instead overloaded the left pinky with the windows key. And on the right pinky, it's function and menu keys. That made control and alt even harder to use. I think the A500 keyboard layout was better in every respect where the control key is where the caps lock key is now. Less keyboard options forced people to think more about software design.
