I was using my friend's Microsoft Surface Ergonomic Keyboard when I was staying at their house for a few days. I really liked the keyboard so I bought one for myself. It's been great so far, and my only issue with it is the function key (Fn). Pressing Fn just toggles a light on the key, and it doesn't actually send any keypress event, so I couldn't figure out how to start dictation. It took me quite a while to figure out how to solve this problem, but I had a lot of fun and really enjoyed figuring it out. I thought I write up a detailed answer on StackExchange and post on HN. I'm really impressed with Karabiner-Elements. They have a documentation site [1] with some really interesting examples for complex rules. I like the idea of setting up keyboard shortcuts to launch apps [2]. There's also a safeguard for command-q, so you always have to press it twice. (Google Chrome already does this, so you could even set up a condition to ignore the rule if Google Chrome is the active application.) I'm looking forward to coming up with more ideas for shortcuts and workflows. This is like having bash aliases for your entire operating system. For me, backlit keys on a laptop is nice because I'll use a laptop in a dark environment and they layout isn't the same as my desktop keyboard so my touch typing isn't always 100%. When I'm at my desktop, the room is always brightly lit. My rant was directed at desktop keyboards that have customizable LEDs. They come with custom software that let you specify the colors on each individual key. And yes, the colors can change based on your current layer. I was lamenting the cost associated with engineering the LEDs into the keyboard's circuit, and the cost of writing the custom software UI and embedded software on the keyboard to control the LEDs. I read a bit more about the company Dygma. It appears they started as a gaming keyboard company, and are now entering the ergonomics market. It makes more sense now why they included the LEDs. They have already written the software UI and have the engineering experience. My personal keyboard is a Kinesis Freestyle Pro. It's a huge improvement from my Microsoft Surface Ergonomic Keyboard, but it doesn't completely cure my RSI. The only total cure I've found for that is to not type for a living :( . I've tried a lot ... although I haven't tried diet adjustment yet.
