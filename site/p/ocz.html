On a related note, I had a OCZ SSD back in the days which bricked itself all of a sudden. I was running nightly full-disk cloning of my disk via TrueImage, in addition to "realtime" backup of my user directory via Crashplan (back when they were good), so I was back up and running in less than 30 minutes with no important data loss. I know there are tools like Restic that can do what Crashplan did, but what's the TrueImage equivalent for Linux? Ie something I can use to clone my primary disk nightly in the background, including boot partition, incrementally with periodic full clones, and that supports resizing partitions (both up and down) in case the replacement disk isn't of equal size?
