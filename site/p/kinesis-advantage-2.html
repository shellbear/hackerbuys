I use Kinesis Advantage 2 for work, but I don't use it to play video games. First, it's kind of expensive, and games wear the keyboard very quickly, second: game designers assume a more conventional keyboard layout, so, for example, small function keys are a non-starter for a lot of games. Also, games assume that the player should be able to press keys 6-0 with the same hand they press 1-5 (while holding the mouse in the other hand) -- this doesn't work well with split keyboards. I would expect the same to be true, more or less for this keyboard. With the exception of function keys being bigger. On the other hand, I'm not sure I'd want function keys to not be very easily distinguishable from the rest. At least, in the case of Kinesis, some of them control keyboard's own macros / remapping. Accidentally hitting those might result in an hour long break trying to reprogram the keyboard to do what it used to do before you fat-fingered it to do something stupid.
