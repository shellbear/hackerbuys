i915 is still the main kernel mode driver on Linux for every Intel GPUs up to Alchemist. xe kmd is used by Battlemage by default (as of 6.12). There's a Mesa DRI driver, called i965 (originally made for Broadwater chipset, thus the 965 numbering), which has since been replaced by either: - Crocus for anything up to Broadwell (Gen 8) - Iris for anything from Broadwell and newer Then there's a Video Acceleration driver, which is (also) called i965. I think this is what you're referring to. There are: - i965 (aka Intel VAAPI Driver), which supports anything from Westmere (Gen 5) to Coffee Lake (Gen 9.5) - iHD (aka Intel Media Driver), is a newer one, which supports anything from Broadwell (Gen 8) - libvpl, an even newer one, which supports anything from Tiger Lake (Gen 12) and up Battlemage users had to use libvpl until recently because Media Driver 2024Q4 with BMG support was only released 2 weeks ago. Using libvpl with ffmpeg may requires rebuilding ffmpeg, as some distro doesn't have it enabled (due to conflict with legacy Intel Media SDK, so you have to choose). I have B580 for my Linux machine (6.12), and xe seems pretty stable/performant so far.
