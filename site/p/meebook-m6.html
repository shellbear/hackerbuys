I bought a second hand Meebook M6 on ebay. At least, it was listed as second hand but seemed to be fresh out of the box when it arrived. I completely love it. For actually reading ebooks, I'm using Koreader instead of the built-in reader because I find the UI a bit easier to get my head around. I mostly use it for PDFs related to classroom learning, but have the odd epub knocking around from project gutenburg etc. It has Google Play support, so I can use the Libby app to access my local library's ebook collection (including offline access to travel guides - so useful). I also use the Sefaria app to read Hebrew scripture (also supports offline). These apps tend to use the battery faster than Koreader and having scrolling controls instead of page-turning controls is a bit of a pain, but quite manageable. I haven't tried the Kindle app, but I'm sure it would work fine.
oddeyed, 2026-05-23 in “Kindle loyalists scramble as Amazon turns page on old e-readers”
