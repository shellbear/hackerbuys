The first step would be to define what you want (& why & their priority for your budget), you would then search & select single components based on that. The what you want -step is really really important. E.g. I just built a PC ("Fractal Define R5" case + 3 low-RPM Noctua fans + MSI X570S motherboard + 128MiB RAM Kingston + 5 2TB NV2 Kingston NVMe + 1 AMD Ryzen 9 5950X + the only PCIe x1 GPU I could find which turned out to be nVidia) to run a Postgresql DB server. In my case I specifically ended up selecting for example MSI's X570S motherboard because it doesn't have an active fan for its chipset, the Ryzen 9 5950X because it has so many CPU cores that it would be able to manage my workload even when its "boost"-feature is disabled (in my case -15% less work done without CPU "boost" but at the same time with as well -33% watts used), all this because of wanting to have as less heat and noise as possible because I host this in my flat (trying to save $ by replacing a server which I used to host with "hetzner.com" for 100$/month). In your case your usecase will probably be different.
