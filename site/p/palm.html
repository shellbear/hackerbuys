Toward the end I was using PalmOS almost exclusively with fingertip input rather than a stylus. The 5-way navigator on newer devices is still arguably better than anything we have on modern smartphones; you could page through Launcher categories using the hardware button, select an app using up/down left/right and open it with the center button.
