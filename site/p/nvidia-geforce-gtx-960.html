+1 to using Frigate. I've had it running on my home server for a couple of years and it has served us very well. Detect is running on an old GTX 960 I had laying around, and it works a charm (though I'll probably run out of legroom once I bring up more cameras). One of the big advantages is that I can pick and choose which camera I use, and then segment it off on it's own firewalled VLAN so it's only talking to my server applications. That lets me know that its not phoning home, and I can run PoE cameras that are immune to wifi jammers. The idea that the surroundings of my house aren't being beamed straight into an Amazon datacenter somewhere is particularly satisfying.
