That's exactly what `A && !B` expresses. | A | B | `A && !B` | Output | |---|---|-----------|--------| | (T) | (F) | `T && T = T` | | | (T) | (T) | `T && F = F` | | | (F) | (F) | `F && T = F` | | | (F) | (T) | `F && F = F` | | ### In Rust: ```rust if A && !B { // output is true } else { // output is false } ``` This is the most direct and idiomatic way to express that logic.
