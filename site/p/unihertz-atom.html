I almost bought one, but it felt hacky to use this it in the USA (lack of frequencies & Google Play) After failing to find a dumb phone that was as flexible as I wanted, I ended up writing a shell script to turn an Android phone into a dumb phone: https://github.com/tstromberg/quietude * For a true "dumb phone" experience: `quietude.sh disable all` * For a less distracting experience: `quietude.sh disable distractions` The key here is that the script disables things in a way that you can only enable if you plug the phone in with a USB cable, which keeps you from re-enabling it when you are bored in line somewhere.
