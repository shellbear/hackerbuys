Step 2 is to connect a TV box, but if you replace Samsumg, LG, or Google by Apple or Amazon, you have made no progress at all towards privacy. Having researched this topic extensively, there are two main options for real user control and privacy. First, you can run an ordinary Linux distro on a mini PC, with a "launcher" such as Plasma Bigscreen. It's fine with an airmouse, but you will be mostly running upscaled desktop apps that aren't remote or controller friendly. The best solution is actually to keep the mini PC and compile Lineage OS (Android TV 17) for a generic x86 target. This is a true degoogled Android TV distro that can, with some more hacking, run any ARM TV app from F-Droid, Aurora or other source. It is by far the best solution in that it is a true 10-foot UX and is compatible with almost all TV apk apps out there. The downside is that this not exist off-the-shelf. I spent a couple of days putting this together with Claude and it takes several hours to compile.
