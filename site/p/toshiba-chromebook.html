If anyone wants to run Linux apps on their Chromebook right now, you can just install GalliumOS. I think it's better than the VM solution that's mentioned in the article because GalliumOS gets installed natively, so there's no VM. You can choose to dual boot it with ChromeOS. It runs really well, and it's hyper optimized for Chromebooks. It's just a fork of xubuntu. I've been running it on my Chromebook for 2 years and I use it as a portable development machine. It's nice having a $350 laptop with a 1080p IPS screen, SD ports, enough computing power to run Dockerized web apps and weighs under 3 pounds.
