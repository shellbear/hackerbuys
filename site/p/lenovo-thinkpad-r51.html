I've got a ThinkPad R51 (1.5GB and a 1.4GHz single core Centrino running Lubuntu) that's about 11yrs old still going well. It has had a mug of coffee spilt over the keyboard while running which it survived just fine after some cleaning and drying. But its usefulness is coming to an end. It's got a non PAE 32bit cpu, which isn't a configuration supported by many currently supported distros any more. The battery doesn't last that long any more either.
