Likes itOwned 2 yearsStill going
I've been using mine (13-inch) for a couple years now. Like others, I would've got the AMD mainboard but it wasn't out yet, so I settled for the Intel 12th gen. When I first got it, the touchpad didn't click properly. There was a bit of back and forth with support (they wanted to see video of the issue) but all in all, they shipped the replacement part within 3 days of the report. That's acceptable, in my book. Then there was a very strange issue where the machine would randomly shut down while sleeping, seemingly related to using Windows 11 with the 12th gen CPU. Turns out you need to disable 'connectivity in modern standby' if this is the case: POWERCFG -SETDCVALUEINDEX SCHEME_CURRENT SUB_NONE CONNECTIVITYINSTANDBY no 0 POWERCFG -SETACVALUEINDEX SCHEME_CURRENT SUB_NONE CONNECTIVITYINSTANDBY 0 Anyway, aside from that, I've had no issues. The main benefit in my view is that you don't need to worry about 'timing', in terms of generational improvements in the hardware. In my case, I didn't get the AMD CPU I wanted, but when I decide to upgrade, I can do so for a pretty reasonable price: https://frame.work/gb/en/products/mainboard-kit-amd-ryzen-70... . Likewise, if any component breaks, I can be confident it's not going to cost me the whole machine, and I can do all the servicing myself. This would be inconceivable in any other laptop, especially one of this form factor.

I disagree with this characterization, in two ways: 1. This is a Linux-friendly laptop for the most part, but it's still built with Windows as the primary OS (and the only one you can get preinstalled). When you're building things with Linux kernels in mind, it's easy to pick current hardware that supports Linux optimally (see also: every Chromebook). 2. The places where this laptop isn't perfect are _nothing_ like the problems Linux laptops had twenty, or even ten, years ago. I used a Thinkpad with Ubuntu in 2012, and it worked pretty well... but also ran super-hot and burned through battery ridiculously quickly. The Framework doesn't do that. Sure, it doesn't have amazing battery life (around 5-6 hours), but it also doesn't have amazing battery life in Windows; it's just the nature of the hardware. The automatic-brightness thing is real, but relatively minor compared to all the rest of the hardware (Wifi, fingerprint reader, etc) working smoothly.
