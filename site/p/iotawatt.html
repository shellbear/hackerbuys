Recommends it
If anyone is interested in having this type of real-time usage data for their own own home, I highly recommend IoTaWatt: https://iotawatt.com It's a completely local energy monitor that you can install into your home's circuit breaker panel, and then view dashboards or read data via an API from a local web server running on-device. You choose how many sensors you want, but you can monitor your whole home as well as individual circuits. For example, I track and trigger automations when my various appliances (laundry, dishwasher, microwave, etc) start/stop. It's very cool. Just be warned that it does require some research, basic understanding of electricity, and comfort working with high voltage mains connections if you plan to DIY it but I found it approachable and easy to setup. What it looks like: https://i.ibb.co/qBVmBD1/IMG-1595.jpg

Likes it
I am using IotaWatts to do monitoring of every circuit in my house, and it is a pretty great setup. I have a reasonable large setup given I have 9 panels to monitor with >120 individual circuits. I also have it monitoring my 20kw Solar system as well as 42kwh of batteries. https://community.iotawatt.com/t/sorta-larger-than-average-i... I have all of the data going into influx, with grafana for display. During the build of my house I planned for this by adding additional space below the panels: https://www.garagejournal.com/forum/threads/jeffs-mountain-s... However that was more of a nice to have, not something you have to do. On the solar side, if you want per panel measurements that is something you can really only do with micro-inverters. I'm using Enphase 7A micro-inverters on each panel, so I also get direct data from enphase/enlighten about power production from each panel.
