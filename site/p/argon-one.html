My Raspberry Pi 4 has been used to run both a Jitsi and Trackmania server over the years. I never considered using the SD card since it can boot and run from a USB 3 flash drive. Later on, I picked up an Argon One case to add a SATA SSD. Thankfully, modern Rockchip SBCs tend to come with NVMe slots.

Indeed; Argon makes the One case which mates an NVMe SSD to the Pi and includes full size HDMI ports, among other nice features... I've used their other cases for years and they offer a lot more value for the money (and keep it plenty cool). It's surfaces are flat enough to mate with many water blocks. EDAtec has introduced a few fanless enclosures, and other case manufacturers are following suit. The Pi 5 is only a little more power-hungry than the Pi 4. I don't know if there's an official 'published' TDP, but I've never seen total system draw over 15W (including two NVMe SSDs, one via PCIe, one USB 3), so I can't imagine it's more than 8 or 10W. It's still fun to water cool [insert device here], it's just completely unnecessary in this case.
geerlingguy, 2024-02-21 in “Water cooling is overkill for Pi 5”
