Not really, provided the duty cycle is low enough. Espressif chips can be set up so that they boot, run some code and then shut down with a timer (deepsleep). You can stretch the battery quite far that way. I did this to monitor temperature in an outdoor pool. Omega sell plenty of WiFi connected industrial sensors (with small batteries) that are specced to run for a year or so before a recharge. Usually they report measurements on the order of minutes. I also have a Bluetooth HRM which I've used for years (probably days of use, cumulatively). I've maybe changed the battery once.
