The sad state behind KaiOS is that the dev docs are basically useless. There is this guy who maintains bananahackers.net (which is a google page) with all kinds of instructions to get debugging going, but if you have a device without the GSM code unlock support then it's kind of useless. I had a nokia 800 tough for a while, and I was having a gaia fork which you could install on it, together with the system apps. Backups of it still there in case anyone is interested, I gave up fighting against the DMCA bullshit takedown requests coming from everywhere. Whatsapp support was kind of weird because they built a custom web client which somehow worked, but not inside Europe and only globally (e.g. when travelling abroad), so I'd assume there was some kind of georegional deal with them being allowed to support KaiOS while maintaining their own App for it. Oh, before I forget it: most unlock procedures rely on the Android kernel rooting technique that has a MediaTek chipset, because the SDK app was leaked a while back. So if you plan on developing anything, you should choose a MediaTek chipset which is a little older (pre-2018 ish).
